## Завдання № 1 (Пункт 1)

### 1. Умова завдання
Обчислити суму ряду:
$$\sum_{i=1}^{k} \sqrt{m \cdot \frac{1}{i}} \cdot \sin(m \cdot i), \quad k \le 30$$

### 2. Програмний код (`Task1.java`)
```java
package lab03;

/**
 * Лабораторна робота №3, Завдання 1 (Варіант 1).
 * Обчислення суми ряду: sum_{i=1}^{k} sqrt(m * (1/i)) * sin(m * i), k <= 30.
 */
public class Task1 {

    public static void main(String[] args) {
        // Дозволені комбінації аргументів
        printResults(1, 1.0);
        printResults(5, 2.0);
        printResults(10, 0.5);
        printResults(30, 1.5);
        printResults(15, 0.0);

        // Заборонені комбінації (виклик IllegalArgumentException)
        printResults(0, 1.0);           // k < 1
        printResults(31, 1.0);          // k > 30
        printResults(-5, 2.0);          // k < 0
        printResults(10, -2.0);         // m < 0
        printResults(10, Double.NaN);   // m = NaN
        printResults(10, Double.POSITIVE_INFINITY); // m = Infinity
    }

    /**
     * Обчислює суму скінченного ряду.
     *
     * @param k верхня межа (1 <= k <= 30)
     * @param m параметр (m >= 0)
     * @return значення суми
     * @throws IllegalArgumentException у разі виходу за допустимі межі
     */
    public static double calculateSum(int k, double m) {
        if (k < 1 || k > 30) {
            throw new IllegalArgumentException("Параметр k має бути в межах 1 <= k <= 30: k = " + k);
        }
        if (m < 0 || Double.isNaN(m) || Double.isInfinite(m)) {
            throw new IllegalArgumentException("Параметр m має бути невід'ємним скінченним числом: m = " + m);
        }

        double sum = 0.0;
        for (int i = 1; i <= k; i++) {
            sum += Math.sqrt(m / (double) i) * Math.sin(m * i);
        }
        return sum;
    }

    static void printResults(int k, double m) {
        System.out.print("k: " + k + " m: " + m + " result: ");
        try {
            System.out.println(calculateSum(k, m));
        } catch (IllegalArgumentException e) {
            System.out.println("EXCEPTION! " + e.getMessage());
        }
    }
}
```

## Завдання № 2 (Пункт 6)

### 1. Умова завдання
Обчислити значення кусково-заданої функції:
$$x(t, i) = \begin{cases} \sqrt{t}, & i = 1 \\ \frac{1}{\sqrt{t}}, & i = 2 \\ \sum_{k=1}^{i} k \cdot t, & i \ne 1, \; i \ne 2 \end{cases}$$

### 2. Програмний код (`Task6.java`)
```java
package lab03;

/**
 * Лабораторна робота №3, Завдання 2 (Варіант 1 / Пункт 6).
 * Обчислення значень кускової функції x(t, i).
 */
public class Task6 {

    public static void main(String[] args) {
        // Дозволені виклики для різних гілок
        printResults(4.0, 1);
        printResults(0.0, 1);
        printResults(4.0, 2);
        printResults(2.0, 3);
        printResults(1.5, 4);

        // Заборонені комбінації (виклик IllegalArgumentException)
        printResults(-4.0, 1); // t < 0 під коренем
        printResults(0.0, 2);  // ділення на нуль
        printResults(-1.0, 2); // t < 0 під коренем
        printResults(5.0, 0);  // i < 1
        printResults(5.0, -2); // i < 1
        printResults(Double.NaN, 1);
    }

    /**
     * Обчислює значення функції x(t, i).
     *
     * @param t аргумент t
     * @param i параметр гілки i (i >= 1)
     * @return значення функції
     * @throws IllegalArgumentException при порушенні ОДЗ аргументів
     */
    public static double calculateFunction(double t, int i) {
        if (Double.isNaN(t) || Double.isInfinite(t)) {
            throw new IllegalArgumentException("Параметр t має бути скінченним числом: t = " + t);
        }
        if (i < 1) {
            throw new IllegalArgumentException("Параметр i має бути цілим числом >= 1: i = " + i);
        }

        if (i == 1) {
            if (t < 0) {
                throw new IllegalArgumentException("Для гілки i = 1 параметр t має бути >= 0: t = " + t);
            }
            return Math.sqrt(t);
        } else if (i == 2) {
            if (t <= 0) {
                throw new IllegalArgumentException("Для гілки i = 2 параметр t має бути > 0: t = " + t);
            }
            return 1.0 / Math.sqrt(t);
        } else {
            double sum = 0.0;
            for (int k = 1; k <= i; k++) {
                sum += k * t;
            }
            return sum;
        }
    }

    static void printResults(double t, int i) {
        System.out.print("t: " + t + " i: " + i + " result: ");
        try {
            System.out.println(calculateFunction(t, i));
        } catch (IllegalArgumentException e) {
            System.out.println("EXCEPTION! " + e.getMessage());
        }
    }
}
```

## Завдання № 3 (Пункт 11)

### 1. Умова завдання
Обчислити нескінченну суму із заданою точністю $\varepsilon$ ($\varepsilon > 0$):
$$\sum_{i=1}^{\infty} \frac{1}{i^2}$$
Вважати, що необхідна точність досягнута, якщо черговий доданок виявився по модулю меншим, ніж $\varepsilon$. Цей і всі наступні доданки не враховуються.

### 2. Програмний код (`Task11.java`)
```java
package lab03;

/**
 * Лабораторна робота №3, Завдання 3 (Варіант 1 / Пункт 11).
 * Обчислення нескінченної суми ряду: sum_{i=1}^{inf} 1/(i^2) із точністю eps.
 */
public class Task11 {

    public static void main(String[] args) {
        // Дозволені виклики
        printResults(0.1);
        printResults(0.01);
        printResults(0.001);
        printResults(1e-5);

        // Заборонені комбінації (виклик IllegalArgumentException)
        printResults(0.0);
        printResults(-0.05);
        printResults(Double.NaN);
        printResults(Double.POSITIVE_INFINITY);
    }

    /**
     * Обчислює суму нескінченного ряду із заданою точністю.
     *
     * @param eps допустима похибка (eps > 0)
     * @return обчислена сума
     * @throws IllegalArgumentException якщо eps <= 0 або не є дійсним числом
     */
    public static double calculateInfiniteSum(double eps) {
        if (eps <= 0 || Double.isNaN(eps) || Double.isInfinite(eps)) {
            throw new IllegalArgumentException("Параметр точності eps має бути > 0: eps = " + eps);
        }

        double sum = 0.0;
        long i = 1;

        while (true) {
            double term = 1.0 / ((double) i * i);
            if (Math.abs(term) < eps) {
                break;
            }
            sum += term;
            i++;
        }

        return sum;
    }

    static void printResults(double eps) {
        System.out.print("eps: " + eps + " result: ");
        try {
            System.out.println(calculateInfiniteSum(eps));
        } catch (IllegalArgumentException e) {
            System.out.println("EXCEPTION! " + e.getMessage());
        }
    }
}
```

## Відповіді на контрольні питання

### 1. Що таке структурне програмування?
Структурне програмування — це методологія розробки програмного забезпечення, що базується на представленні алгоритму у вигляді чіткої ієрархічної структури блоків без використання безладних переходів. Відповідно до теореми Бема — Якопіні, будь-який обчислюваний алгоритм може бути представлений за допомогою трьох базових керуючих конструкцій: послідовності дій, розгалуження та повторення (циклу).

### 2. Назвіть основні конструкції структурного програмування.
1. **Послідовність (Sequence):** послідовне поетапне виконання інструкцій одна за одною.
2. **Розгалуження (Selection / Alternative):** вибір виконання однієї з кількох гілок коду залежно від істинності умови (`if`, `if-else`, `switch`).
3. **Цикл / Повторення (Iteration / Loop):** багаторазове повторення блоку дій, доки виконується задана умова (`while`, `do-while`, `for`).

### 3. Назвіть основні принципи структурного програмування.
* **Декомпозиція (низхідне проєктування зверху-вниз):** розбиття складного завдання на прості підзадачі.
* **Модульність:** виділення логічно завершених фрагментів алгоритму в окремі методи чи підпрограми.
* **Принцип одного входу й одного виходу:** кожен структурний блок та підпрограма повинні мати лише одну вхідну точку та одну точку завершення.
* **Відмова від безумовних переходів:** уникнення операторів на кшталт `goto` для забезпечення передбачуваного лінійного/ієрархічного потоку виконання.

### 4. Поясніть, чому в більшості мов програмування не радять використовувати оператор GOTO, а в мові Java його взагалі немає?
Використання `goto` спричиняє безладні стрибки між довільними ділянками коду, перетворюючи логіку на «спагеті-код», який дуже важко супроводжувати, налагоджувати та оптимізувати компілятором. 

У Java ключове слово `goto` зарезервоване (щоб його не використовували для назв змінних), але не реалізоване. Замість нього використовуються структуровані конструкції (цикли, умовні оператори), система винятків (`try-catch-finally`), а також мічені оператори `break` та `continue`.

### 5. Що таке спагеті-код?
Спагеті-код (Spaghetti code) — це зневажлива назва заплутаного, погано структурованого коду з незрозумілим потоком керування. Його складно читати та підтримувати через відсутність модульності, надмірне використання переходів або занадто глибоку заплутану вкладеність умов.

### 6. Що таке проектування зверху-вниз? В чому його переваги?
Це підхід до розробки, коли спочатку формулюється загальна високорівнева логіка алгоритму (основні кроки), а потім кожен крок поступово деталізується та розбивається на простіші компоненти (методи, модулі).
* **Переваги:** дозволяє зосередитися на ключовій архітектурі, не відволікаючись на дрібні деталі; полегшує розподіл роботи між розробниками та прискорює тестування за допомогою створення методів-заглушок.

### 7. Що таке область видимості ідентифікатора?
Область видимості (Scope) — це контекст програми (частина вихідного коду), всередині якого певний ідентифікатор (змінна, метод, клас тощо) є доступним, дійсним і може бути використаний за своїм ім'ям.

### 8. Що таке блок? Як блоки впливають на область видимості?
Блок — це група операторів, обмежена фігурними дужками `{ }`.  
* Локальні змінні, оголошені всередині блоку, існують і видимі лише всередині цього блоку та вкладених у нього підблоків.
* Після закриття дужки `}` блок завершується, а оголошені в ньому змінні знищуються.
* У Java заборонено повторно оголошувати змінну з тим самим ім'ям у вкладеному блоці, якщо вона вже була оголошена у зовнішньому блоці цього ж методу.

### 9. Наведіть приклади, у яких випадках краще використовувати наступні оператори та конструкції:
* **`if`:** коли дію потрібно виконати тільки у разі виконання умови, а за умови `false` — нічого не робити:
  ```java
  if (value < 0) {
      throw new IllegalArgumentException("Параметр не може бути від'ємним");
  }
  ```
* **`if-else`:** коли є дві взаємовиключні дії:
  ```java
  if (n % 2 == 0) {
      System.out.println("Парне");
  } else {
      System.out.println("Непарне");
  }
  ```
* **ланцюги `if-else if-else if...`:** для послідовної перевірки неперетинних діапазонів чи складних умов:
  ```java
  if (score >= 90) grade = 'A';
  else if (score >= 75) grade = 'B';
  else grade = 'C';
  ```
* **`switch`:** коли перевіряється точне співпадіння однієї змінної з фіксованими дискретними константами (`int`, `char`, `enum`, `String`):
  ```java
  switch (dayOfWeek) {
      case 1 -> System.out.println("Понеділок");
      case 2 -> System.out.println("Вівторок");
      default -> System.out.println("Інший день");
  }
  ```
* **тернарна операція `?:`:** для лаконічного вибору значення безпосередньо у виразі:
  ```java
  int max = (a > b) ? a : b;
  ```

### 10. Наведіть приклади, у яких випадках краще використовувати наступні оператори та конструкції:
* **`while`:** цикл із передумовою. Використовується, коли кількість ітерацій наперед невідома і тіло може взагалі не виконатися жодного разу:
  ```java
  while (scanner.hasNextInt()) {
      sum += scanner.nextInt();
  }
  ```
* **`do-while`:** цикл із післяумовою. Використовується, коли тіло має виконатися щонайменше один раз (наприклад, валідація введених користувачем даних):
  ```java
  do {
      System.out.print("Введіть число > 0: ");
      val = scanner.nextInt();
  } while (val <= 0);
  ```
* **`for`:** цикл із лічильником. Використовується, коли кількість повторень або діапазон індексів відомі заздалегідь:
  ```java
  for (int i = 1; i <= k; i++) {
      sum += i;
  }
  ```

### 11. Чим оператор break відрізняється від оператора continue?
* **`break`:** миттєво перериває виконання всього циклу або блоку `switch` і передає керування на перший рядок коду після цього циклу/блоку.
* **`continue`:** перериває лише поточну ітерацію циклу, пропускає команди після себе і одразу переходить до перевірки умови (та інкременту лічильника) для наступної ітерації.

### 12. Навіщо у мові Java є мітки, якщо немає goto?
Мітки у Java використовуються виключно у поєднанні з операторами `break` та `continue` для керування потоком у **вкладених циклах**. Вони дозволяють перервати не тільки внутрішній цикл, а й вийти з зовнішнього або перейти на його наступну ітерацію:
```java
outerLoop:
for (int i = 0; i < rows; i++) {
    for (int j = 0; j < cols; j++) {
        if (matrix[i][j] == target) {
            found = true;
            break outerLoop; // вихід з обох циклів
        }
    }
}
```

### 13. До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.
```java
boolean a = false;
boolean b = false;        
if (a=false) {
    System.out.println("a is false");
} 
if (b=true) {
    System.out.println("b is true");
}
if (a=b) {
    System.out.println("a = b");
}
```
**Результат:**
```text
b is true
a = b
```
**Пояснення:**  
Умова кожного `if` містить оператор присвоєння `=`, а не оператор рівності `==`. Значенням виразу присвоєння є присвоєне значення:
1. `(a=false)` повертає `false` $\rightarrow$ блок не виконується.
2. `(b=true)` встановлює `b` в `true` і повертає `true` $\rightarrow$ на консоль виводиться `"b is true"`.
3. `(a=b)` встановлює `a` в поточне значення `b` (`true`) і повертає `true` $\rightarrow$ на консоль виводиться `"a = b"`.

### 14. До якого результату призведе виконання наступного фрагменту коду? Перевірте. Поясніть.
```java
int a = 1;
a++;
++a;        
switch(a) {
    case 1: System.out.println("1");
    case 2: System.out.println("2");
    case 3: System.out.println("3");
    case 4: System.out.println("4");            
}
```
**Результат:**
```text
3
4
```
**Пояснення:**  
Початкове значення `a = 1`. Після постфіксного `a++` значення стає `2`, а після префіксного `++a` стає `3`.  
Оператор `switch` передає керування на мітку `case 3:`. Оскільки після виводу немає оператора `break`, спрацьовує ефект провалювання (fall-through), і програма автоматично виконує наступну гілку `case 4:`.

### 15. До якого результату призведе виконання наступного фрагменту коду (true/false)? Перевірте. Поясніть.
```java
double sum = 0;                
// Let's find: 1 + 1/2 + 1/3 + 1/4 + 1/5 + ...
for(int i=1; i<10; i++) {
    sum = sum + 1/i;
}
System.out.println(sum > 1);
```
**Результат:**
```text
false
```
**Пояснення:**  
У виразі `1 / i` обидва операнди є літералами/змінними цілочисельного типу `int`. Тому виконується цілочисельне ділення з відкиданням дробової частини:
* При `i = 1`: $1 / 1 = 1$.
* При `i >= 2`: результат ділення завжди дорівнює `0` ($1 / 2 = 0$, $1 / 3 = 0$ тощо).  
Таким чином, у змінній `sum` накопичується значення `1.0`. Умова `1.0 > 1` повертає `false`. Для отримання правильної математичної суми слід використовувати дійсне ділення: `1.0 / i`.
